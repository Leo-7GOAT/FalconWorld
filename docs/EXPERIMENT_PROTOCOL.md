# 冻结实验协议 v1（正式测试前登记）

日期：2026-10-28。目标是辨别世界模型的收益及负结果，不以测试调参。

## 数据和场景

纵向 constant/mild/brake/stopgo，独立 episode 固定 seeds；ID 和 OOD 分开，训练/验证/测试按完整 episode 分割。仅训练集拟合尺度和物理参数。测试不参与网络 early stopping、风险校准或计算预算选择。

主指标：碰撞原始计数、完成率、进度 m、间距目标 RMSE m、实际速度差分 jerk RMS m/s³、回退次数、模型推理与完整控制周期 p50/p95 ms、周期超过100ms比例。完成指跑满任务时长且进度至少参考前车进度50%，停车场景参考下限5m。所有结果保留失败，碰撞早停不可因此降低错误指标而不报告失败。

开环每episode固定非重叠起点，递归0.5/1/3秒，gap/ego/lead/actuator分别给SI单位MAE；不以混合单位MSE作结论。概率分歧只报告经验覆盖/宽度，不称已校准置信度。

## 预算

- smoke：1训练seed，每场景族2个配对episode，每episode80步，64候选×30步×3迭代；用于全路径验证，无统计优势结论。
- standard：3训练seeds，每seed每场景族每分布10个独立配对episode（场景seed跨训练seed不重复，合计每族ID30、OOD30），每episode100步；先由train/val profile测定可执行候选数，固定后执行测试。
- full：5训练seeds，每族60episode，150步，增加候选预算。

若实测成本需要降低预算，先记录原因，不把简化结果标成standard达标。

2026-10-28 预算修订：初始实现误按每训练seed都重复同一30场景，约需数小时；改为每seed10个不同场景，仍满足每族每分布30独立配对回合、3训练seed。初始运行在约180/2400回合时停止并保存为 outputs/standard_initial_budget_trial，不用于正式结论，未读取其驾驶指标来选择模型或控制参数。时间预算采用最小候选完整周期确定共同目标；物理候选搜索上限扩到16384，以避免固定开销使候选数比例推算失真。
统一动作[-6,2]m/s²，常规变化率8m/s³，紧急回退可越过舒适性速率限制；目标12m/s、目标间距4+1.2v。物理/学习共享任务代价、时域、初始化seed及回退。ACC是独立经典对照。

## 消融和统计

物理CV、物理CA、丰富物理、全学习、残差、有无历史、物理自车+学习前车、集成有无风险。强物理允许非对称速度相关机制。动作分支在相同状态历史下固定候选动作，与环境独立分支比较。

相同计算量主比较；另在验证数据测完整控制周期，给每模型选择候选数达到相近墙钟预算（候选数下限/波动应报告），不能宣称严格硬实时。配对bootstrap以episode为单位；跨训练seed给分层区间，同一个场景seed不可当成3个独立新场景。报告样本数和原始记录。

本版本最多一次初始训练与一次基于验证失败的修复；结构性bug可修复并记录，测试不能用于挑胜者。

## 附加验证研究登记（2026-11-04，原正式实验不变）

触发依据仅为验证集诊断：历史前车网络在匀速val族单步误差很小但递归漂移显著；组件交换指向前车预测而非自车残差。允许使用原协议的一次验证失败修复预算，研究CA加稳定历史修正/低阶AR残差。只用train拟合、val选择，禁止读取test调参；保持自车强物理和原任务约束。候选在独立模块/目录，原冻结训练模型、控制器和所有正式回合不变。先交付val按族递归指标与耗时；val无额外收益就保留负结果，不继续搜索。若val支持附加测试，先固定参数、方法集合、配对场景与计算预算，再只作一次完整测试，作为附录而非替换主实验。参数辨识/自适应CA仍保留为强对照。
