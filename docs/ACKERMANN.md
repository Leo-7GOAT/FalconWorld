# 二维阿克曼实验

二维主线在 `falconworld/ackermann.py`，入口为 `run_ackermann.py`。它复用项目的 `falconworld.planning.CEMOptimizer`，环境、预测器、规划代价和安全回退分别实现。学习残差确实在每个在线控制周期递归预测候选动作序列，执行最优序列第一步，再读取新状态重新规划。

## 本地复现

在工程根目录使用含 NumPy、SciPy、Matplotlib、Pillow 的 Python 3.11：

```powershell
python -m unittest discover -s tests -p test_ackermann.py -v
python run_ackermann.py --preset smoke --output outputs/ackermann/smoke_verified
python run_ackermann.py --preset standard --output outputs/ackermann/standard_verified
```

上面三个入口均在本工程实际运行。默认进度和原始数据即时写入 `outputs/ackermann/<preset>/`，本次复核显式使用 `smoke_verified` 与 `standard_verified` 目录，保留旧试跑；只有 `run_metadata.json` 存在且 `status` 为 `verified local synthetic simulation`，并且 `completeness.json` 中 `verified_complete=true` 才表示本轮完整结束。标准版训练数据种子为 527、528、529，每个种子10个独立初始场景/场景族，合计每族30回合，其中 ID/OOD 各15回合。4控制器 × 4场景族 × 30回合 × 2计算预算，共960个闭环；不是960个独立训练种子。

`--preset full` 为更大预算入口，尚未执行，不把该档标为已验证。`--pairs N` 可用于显式改变每训练种子的场景数；`--skip-time` 仅运行相同候选预算。这两个覆盖选项应通过 `experiment_registration.json` 区分，不能冒充默认标准档。

## 状态、动作和仿真假设

状态按 `[x, y, yaw, v, a_actuator, delta_actuator]` 排列。`x,y` 是后轴中心位置[m]，正 yaw 为逆时针[rad]，v 为前进速度[m/s]。动作是期望加速度[m/s²]与前轮转角[rad]，不是油门比例、PWM或底盘速度字段。加速度执行器和转角均为本实验的仿真特权状态，不能假设真实车直接提供。

| 量 | 数值/范围 | 含义 |
| --- | --- | --- |
| 时间步长 | 0.1 s | 显式 Euler，各状态使用旧值 |
| 轴距 | 1.0 m | 通用小尺度仿真假设，不是 R550 规格 |
| 车长/车宽 | 1.5/0.7 m | 有向矩形车身 |
| 车身中心相对后轴 | 前方0.4 m | 用于车身碰撞 |
| 指令加速度 | [-3, 2] m/s² | 所有控制器一致 |
| 前轮转角 | ±0.5 rad | 所有控制器一致 |
| 指令变化率 | 加速度5 m/s³、转角0.8 rad/s | 候选序列与执行动作均限幅 |
| 加速时间常数 | `0.35 + 0.04*v` s | 数据生成机制，教学仿真假设 |
| 减速时间常数 | `0.25 + 0.02*v` s | 数据生成机制，教学仿真假设 |
| 转向时间常数 | `0.22 + 0.06*v` s | 数据生成机制，教学仿真假设 |
| yaw 运动学衰减 | `1/(1+0.015*v²)` | 速度相关的简化侧偏效应，不是轮胎动力学标定 |
| OOD | 上述时间常数×1.3，衰减系数×1.3 | 未作为预测输入的较慢执行器响应 |

不叠加随机邻车交互。加减速不对称和速度相关响应已足以检验常参数模型的局限。速度执行 `max(0,v+a*dt)`，停车后仍保留负的执行器状态。jerk 从实际离散速度差得到的加速度计算，不能用执行器状态代替。

车身碰撞使用圆形障碍到有向矩形的带符号距离。道路约束检查车身四角。真实环境步进后对两帧之间的姿态插值，间隔小于车宽的0.1倍，以避免高速穿越障碍被漏检；这是离散几何检查，没有形式化连续安全保证。碰撞或车身越界立即终止，不能通过把负间隙截断来隐藏碰撞。

## 场景和控制器

四场景为直线、正弦曲线、直线变速和静态圆障碍绕行。目标行驶30 m，最长16 s。障碍任务提供一个1.8 m横向隆起的可行参考线，因此它验证的是障碍条件下的轨迹预测和跟踪，尚不包含自主选道或发现拓扑路线。道路宽7 m，所有控制器使用同一路线、障碍物、初始状态和外生条件。

比较对象：

1. `pure_pursuit_pid`：纯跟踪加速度反馈控制器；有前瞻距离，受相同动作与回退约束。
2. `calibrated_physics_mpc`：训练数据最小二乘辨识的常数加速度/转向响应增益和 yaw 增益。
3. `rich_physics_mpc`：允许相同的加减速不对称、速度相关时间常数与 yaw 衰减机制，使用训练数据辨识7参数。不能只给学习方法更丰富的表达能力。
4. `learned_residual_mpc`：常参数物理加16项非线性特征的岭回归残差，学习加速度状态、转角和 yaw 的单步修正。特征包含当前速度、执行器与候选指令差，输出权重由数据训练。它是低维学习残差世界模型，不应称为全隐藏层训练的 MLP。

三个 MPC 使用同一个 CEM 主体与同一个代价：横向/航向/速度跟踪、进度、动作幅值与变化、车身越界与碰撞惩罚和距离余量。每个候选从相同状态出发，预测器递归使用自己的状态；不读取未来真值、隐藏 condition 或环境脚本。

安全回退由独立 `AckermannSafetySupervisor` 处理，所有控制器共享。输入/求解无效、接近障碍的紧急几何条件、周期超100 ms会产生单独原因记录。回退不是无条件保证；日志保留回退次数和碰撞/完成指标，不允许回退掩盖规划失败。

## 数据、训练与冻结评估

每训练种子生成54个完整自由空间激励episode，每个100步；采集时不放置道路与障碍，辨识动力学而非碰撞策略，闭环任务才施加道路/障碍终止。episode 0–35训练，36–44验证，45–53冻结测试。训练输入包括当下状态和实际受限动作，标签是下一状态。没有跨集合相邻帧，没有使用测试数据做参数辨识或选模型。该轻量残差不使用数据归一化。岭系数只在 `[1e-6, 1e-4, 0.01]` 中按验证单步误差选择。常参数与丰富物理的全部辨识也只用训练集。

三训练种子改变训练数据采集与独立拟合；岭回归本身没有随机优化器。闭环场景随机种子为训练数据种子+1000，在每组所有控制器之间完全配对，训练种子之间使用独立场景。三个种子因此代表三次独立数据采集/拟合及场景组，不是固定数据上三个神经网络初始化。

开环在每个冻结测试episode的0、20、40、60步处起始，预测1、5、10、30步；递归位置、yaw、速度和转角误差按各自单位记录。窗口共享同一个episode，不能把窗口或相邻帧当成独立统计样本。`paired_effects.json` 的闭环区间以配对episode为重采样单位，数据表另保留训练种子，并给出三个独立拟合的效应均值与训练种子bootstrap区间；仅三个种子的区间分辨率有限。

`action_branches.csv` 从完全相同的初始状态分别执行减速左转、加速右转和保持三组受限动作，记录真实环境分支与各模型递归分支。它检验动作条件响应，不涉及外生前车的因果作用。

## 两种计算预算

相同候选预算：standard 的预测时域25步（2.5 s）、48候选、2 CEM迭代、8精英，对所有模型相同。最大模型单步预测工作量为48×25×2×实际控制周期数，不是只测一次网络前向。

相近时间预算：在独立的固定曲线状态先测量完整 MPC，然后以相同候选预算下最慢中位数×1.2为共同时间目标，二分校准各模型候选数。每次profile含候选、递归时域、代价与优化迭代，profile原始读数及选定候选数在 `profiles.json`。最后仍报告实际闭环周期p50/p95与超时率，profile匹配并不保证运行期每个周期相同。共享主机上同时运行其他训练/评估，计时受系统负载影响，不能据此宣称独占实时性能或 Pi 4B 实时性。

首次性能试跑只按候选数比例估算时间，忽略固定开销，因此被中断并保留到 `outputs/ackermann/profiling_v1_partial/`。正式standard改用独立profile校准，模型、代价和测试场景未因测试驾驶指标调参。该目录不作为正式标准版结果。

## 为什么加入世界模型：证据、收益、代价与适用边界

此实验中的建模问题是常参数执行器无法完全描述速度相关与加减速不对称响应。学习残差能从当前速度及候选指令学习响应修正，改善常参数模型递归预测；候选轨迹随之变化，在线CEM会选择不同转向/加速度序列，日志给出闭环跟踪及平顺性结果。

但本环境无噪声且函数族已知，丰富物理模型能从训练数据恢复真实机制，单步与递归预测接近数值精度。因此相对常物理的改善不能证明相对最强合理基线有额外收益。残差还增加训练数据、模型维护和在线计算，时间预算实验允许物理模型获得更多候选。直线任务经典控制可能优于有限候选CEM；更好的预测也不保证有限优化器的驾驶指标更好。

当前证据仅涵盖合成低维特权状态与静态障碍任务，不涵盖传感器估计误差、真实轮胎/底盘、感知或邻车交互。OOD只是隐藏响应改变，无专门自适应机制，不应声称能可靠识别新车辆。二维模型未单独完成ARM64导出或实车闭环；本实验中的1 m轴距不得写进R550部署参数。
