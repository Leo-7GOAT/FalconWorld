# 补充协议：三个种子的204800步纯PPO参考

日期：2026-11-05（Asia/Shanghai）。入口：`run_sb3_reference.py`，输出：`outputs/rl_sb3/reference_204800/`。机器可核验的事前登记以该目录训练启动前写入的 `registration.json` 为准；本文为其补充说明，不修改已冻结65k正式比较或核心实现。

## 决策依据与目的

65536步成熟PPO标准实验的seed1在固定ID验证集仅完成37.5%、碰撞62.5%、平均raw return -16.65。此前单seed、不同5.2m训练流的官方默认204800步参考成功，无法证明多训练seed下已经有可靠RL基线。因此增加**一次固定更充分训练预算的纯PPO参考**，检查65k预算下的seed不稳定能否通过既定额外训练缓解。

追加预算的依据是上述验证不足；不是根据test胜负选择预算或模型。已有65k研究产物保留，不覆盖、不挑换其中表现不佳的训练seed。新参考无超参数搜索，所有三个seed均固定跑完204800步；达到或未达到门槛都如实报告。不得因为新结果不理想而继续搜索参数或无限加预算。

## 固定设计

| 项目 | 预登记设置 |
| --- | --- |
| 方法 | 纯PPO；沿用成熟SB3默认优化主体 |
| 训练种子 | 0、1、2，全部纳入报告 |
| 每seed真实训练步 | 204800；总614400 |
| 每rollout | 2048真实步、1个环境 |
| 默认优化 | batch64、10 epochs、lr3e-4、ent_coef0、gamma.99、GAE .95、clip .2 |
| 每seed预期优化器更新 | 100rollout × 10epochs × 32minibatches = 32000 |
| 观测、动作和监督 | 与65k实验相同：特权25维固定尺度编码、Discrete5、共同安全监督 |
| reward | 与65k相同：训练raw×.01，验证及测试保留raw单位 |
| 训练环境 | ID；constant/mild/brake/stopgo按episode轮换 |
| 物理训练seed流 | `6000000 + training_seed*100000 + episode_counter` |
| 验证点 | 每seed总51200、102400、153600、204800步，仅监控 |
| checkpoint选择 | 仅最终204800；不早停、不选最佳验证点 |
| 最终测试 | 每seed80回合：4族×ID/OOD×10；三个seed共240 |

204800可被2048整除，本参考没有尾段rollout长度缩小或预算向上取整。相比65k实验，增加训练步与相应默认更新次数；不改变网络/优化超参。三个seed沿用原6m训练流，从头固定训练，所以65k已有训练轨迹与长参考在相同实现及随机条件下具有可比前缀；不把这两次运行当独立训练随机种子。

## 无学习模型训练转移的路径

本入口复用`run_sb3_rl.job`。`method='ppo'`映射得到`predictor=None`，`WorldModelPPO.train`直接调用官方SB3优化路径，跳过合成分支替换。复制的common_data及world_models仅满足既有job的数据/文件API依赖，纯PPO策略和价值更新不读取其中训练样本，也不调用预测器做环境推进。

验收时逐seed核对：`synthetic_generated=0`、`synthetic_replaced=0`、model branch roots为0、模型生成耗时为0、实际真实步204800、实际optimizer updates32000。实际模型预训练占用不算为纯PPO本体训练所需成本；依赖目录复制和共享数据预算字段另列，不把`shared_data_budget_interactions`误称为纯PPO实际使用了离线样本。

## 信息、种子和评估边界

训练只使用原真实合成环境ID脚本，经同一wrapper返回当前观测。7m为验证命名空间、8m为测试命名空间，与6m训练分开；训练seed0/1/2各有独立场景实例。每seed固定8个ID验证回合（每族2个），与65k实验相同，不在验证中加入OOD来再调参。

最终测试使用已有`evaluation_cases(seed,'standard','test')`清单，ID/OOD各40回合。跨三个训练seed，每个场景族/分布有30个独立配对实例；与既有65k方法可以做描述性配对，但训练预算不同，解释必须保留预算差异。

验证采用deterministic predict，不中途load模型、不改变训练RNG。全部训练结束后才保存/重载并核对16个探针的确定动作，再运行一次最终测试。策略输入不含场景脚本、隐藏参数或未来标签。

## 门槛、统计及解读

已有可用门槛保持不变：验证完成率至少0.9、碰撞率至多0.1、平均raw return至少30，三者同时满足。逐seed列出所有四个验证点以及最终门槛结果，不仅报告三seed池化均值。只有8个ID验证场景，门槛通过也不是通用可靠性或安全证明；未通过则明确说明仍没有充分的强RL基线证据。

最终报告全部240测试回合的碰撞/完成/进度、raw return、间距误差、运动学jerk、安全回退及实际计算成本；以episode和训练seed为统计单位，不以相邻帧扩大样本数。零碰撞不构成通用安全保证。

**本参考不是世界模型收益证据，不是204800纯PPO与65536 WM-PPO的等预算优势比较。** 二者在线真实步相差3.125倍，且世界模型另需离线采样/训练和合成计算。新参考只补充较充分纯PPO训练的收敛与seed敏感性背景；世界模型是否节省数据、是否超过强基线，仍需相同观测、任务和明确交互/计算成本的公平对照，不能借预算不同得出胜负。
