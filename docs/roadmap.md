# FalconWorld：后续路线与实验协议

## 当前状态与边界

当前交付是教学脚手架，首课尚未完成；没有已训练世界模型，也没有已验证的性能结论。FalconWorld 使用独立教学目录，未来通过接口接入 FalconPlan，不重写现有规划控制工程。先完成 M1—M4 的单车道闭环，再扩展二维交互和 CARLA。

首课固定 `dt=0.1 s`、`tau_nominal=0.5 s`、加速度指令范围 `[-6, 2] m/s²`，状态为 `[g, v_ego, v_lead, a_actuator]`。`g` 是净间距；`a_actuator` 是施加停车约束前的执行器响应，不等于停车后的 IMU 实测加速度。首课亲手完成状态更新与检查，神经网络留到后续。

## 六个里程碑

| 阶段 | 实现与可测验收 |
| --- | --- |
| M1：任务与物理闭环 | 实现一阶执行器、速度非负约束、间距更新及碰撞记录；加入前车匀速、减速和急刹场景。等速、静止及制动例子须能手算核对，固定种子可复现。 |
| M2：数据与强基线 | 采集完整 episode，记录指令、执行动作与状态。建立前车恒速／恒加速度预测，以及用训练数据辨识参数后的物理模型。输出多时域预测误差，不以故意设错参数的模型作为唯一对手。 |
| M3：学习世界模型 | 先实现确定性小网络，再加入集成或概率输出，并比较物理结构加学习残差。验收包含模型重载、多步滚动预测、概率覆盖率及失败案例；不预设学习模型必须胜出。 |
| M4：CEM-MPC 与 V1 报告 | 用相同规划器分别接物理模型和学习模型，比较风险处理及安全回退的作用。完成固定测试集上的闭环评估、消融和复现记录，才形成第一版结果。 |
| M5：二维交互变道 | 增加车道、车身几何、转向约束和邻车反应。验证同一初始场景下不同自车动作产生的交互差异，并测试后车接近、让行与拒绝让行。 |
| M6：CARLA 适配 | 接入已有 CARLA 0.9.15，核对同步步进、坐标系、时间戳和控制接口。固定场景完成闭环，分别报告直接迁移、参数适配和重训结果。 |

每阶段按“讲清原理—亲手实现—运行观察—代码审查”推进。尚未完成的阶段不能写入成果清单；第一版只称为低维跟驰环境模型，不称为通用交通世界模型。

## 数据、可辨识性与预测协议

按完整 episode 划分训练、验证和测试；相同轨迹的相邻样本不得跨集合。归一化、参数辨识只使用训练集，超参数和概率校准只使用验证集。测试场景固定，并单独设置分布外参数与行为场景。

首课前车按外生恒速模型运动，不受自车动作影响；后续外生急刹也不能被网络学成“自车刹车导致前车刹车”。预测器不得读取未来前车加速度、隐藏脚本或急刹时间。未知执行器参数、前车意图可能需要历史输入，但历史不能保证可辨识，更不能提前知道随机急刹。

不同 `tau_true` 与 `tau_nominal` 仅用于理解模型失配。正式比较必须加入参数辨识后的物理强基线，说明辨识数据及激励范围；战胜故意设错参数的模型不构成创新证据。

分别报告 0.5、1、3 秒的间距误差和两车速度误差，避免用混合单位总误差掩盖问题。概率模型同时报告覆盖率与区间宽度；集成分歧不自动等于可信概率。

## 闭环公平性与结果记录

各方法使用相同观测、CEM、预测时域、动作约束、初始条件和安全回退。预先固定采样与迭代预算，报告计算量和耗时；若比较实时部署能力，另做相同墙钟预算实验。安全回退须报告干预次数，并在仿真中做有／无回退消融。

报告碰撞 `0/N` 等原始计数、最小间距、进度或平均速度、跟驰误差、干预率、jerk、求解耗时 p50/p95 与超时率。jerk 使用速度差分得到的运动学加速度计算，并注明离散周期。急刹测试区分初始条件下可避免与不可避免的碰撞；零碰撞不等于安全保证。

CARLA 的油门、制动、转向归一化量不能直接当作 SI 单位控制量，需单独标定映射。若使用仿真器真值等特权观测，所有对照获得同等信息，并明确结果尚未验证视觉感知闭环。

## 后续强化学习研究

M1—M6 主线是学习模型支持的规划控制，不自动等于基于模型强化学习。后续再研究用模型生成短时想象轨迹来训练策略，对齐真实环境交互预算，并与模型自由策略及 MPC 比较。仅模仿 MPC 输出应称为蒸馏或模仿学习。

方法参考：[PETS](https://arxiv.org/abs/1805.12114)、[MBPO](https://arxiv.org/abs/1906.08253)、[TD-MPC2](https://www.tdmpc2.com/)。这些资料用于学习建模、规划与策略学习方法，不作为本项目或自动驾驶场景已经验证的证据。
