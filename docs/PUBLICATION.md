# GitHub 发布说明

本次发布主线是世界模型辅助 SB3 PPO。源工程原有本地 Git 历史保留；公开仓库从经过整理的当前文件快照开始，不推送本地旧提交。

## 发布范围

- 完整受版本控制的代码、测试、依赖和研究文档。
- `results/sb3_standard/`：正式 21 个任务、1680 个测试回合、原始合成轨迹、21 个最终策略、三个种子的世界模型与共同 train/val 数据。
- `results/ppo_reference_204800/`：延长纯 PPO 参考的 3 个最终策略与 240 个测试回合。
- 旧 MPC 报告附件和旧算法负结果文档保留；旧实验 `outputs/` 全量历史、第三方 CARLA 安装、Python 虚拟环境、个人车辆原始接收日志不发布。

本地用户名路径和设备 SSH 地址在发布副本中替换为占位符。正式合成数据、策略、训练/测试源快照及轨迹字节保持原样；历史审计中的本地库安装路径和模型诊断 manifest 的本地目录仅做路径脱敏。这些路径脱敏不改变科学指标、模型或测试轨迹。结果文件保留原有 Windows 相对路径记法，公开目录映射见 `results/README.md`。

`.gitattributes` 禁止 Git 自动改写换行，以保留注册的源快照、数据和模型 SHA256。公开提交不包含任何密码、访问令牌、个人原始车辆日志或网络设备地址。完整性审计是文件和日志的一致性核验，不是训练每一步的形式化执行证明。

## 使用与验证

先按主 README 准备依赖。发布结果可直接用于离线审计和冻结策略评价；重训命令写入新的 `outputs/`。发布检查记录位于 `results/publication_verification.json`，逐文件校验表位于 `results/SHA256SUMS.json`。实际运行的发布测试、两个结果目录的独立审计和模型加载评价以该记录为准。

本次没有重新进行整个正式训练；发布的是已完成的冻结实验，再验证源代码、结果完整性与可加载性。没有进行车辆连接、部署或 Raspberry Pi 时延测试。
