# FalconWorld: world-model-assisted PPO

FalconWorld is a reproducible simulation research project comparing standard PPO with learned-model and calibrated-physics-assisted training. A compact action-conditioned world model generates fresh short branches from the current real simulator rollout. Model actions, values and log probabilities are frozen before optimization. Half of the PPO training buffer is replaced while preserving the official SB3 optimizer, batch size, epoch count and actual gradient budget. This is a model-assisted PPO experiment, not the original MBPO algorithm.

The registered standard benchmark uses three training seeds and seven methods, with 65,536 online simulator steps per main method/seed. Controls include calibrated physics, no-history and three-step model ablations, extra real-data reuse, and a pure PPO control with the same total native interaction budget including model pretraining. The final frozen policies complete 1,680 paired ID/OOD test episodes. Independent audits check raw trajectory metrics, model/checkpoint hashes, exact data budgets and actual Adam update counts.

The learned-model method records fewer collisions than pure PPO in this sample: ID 2/120 versus 21/120; OOD 11/120 versus 28/120. However, hierarchical return-effect intervals versus pure PPO cross zero, gains are seed-dependent, and some seeds regress. The ID jerk cost is higher. An OOD contrast against physics-assisted PPO supports a limited benefit; it does not establish general superiority or real-vehicle safety. Model generation and pretraining costs are reported separately. Validation diagnostics show that this benefit cannot be explained as uniformly better recursive prediction or a learned ego-dynamics breakthrough.

Current artifacts include 21 trained SB3 policy checkpoints, 24 compact predictor artifacts, fixed dataset manifests, learning curves, cost ledgers, raw trajectories and Chinese research reports. See [the PPO report](SB3_RL_REPORT.md), [model diagnostics](SB3_MODEL_DIAGNOSIS.md) and [the reproduction entry](../README_RL.md).

Scope: low-dimensional longitudinal following in simulation, with privileged actuator state explicitly identified. Existing Ackermann/CARLA MPC experiments remain separate. Raspberry Pi timing acceptance, sensor-based vehicle transfer and real-vehicle deployment are deferred at the user's request.
